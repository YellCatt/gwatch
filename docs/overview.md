# gwatch 功能总览

## 项目简介

gwatch 是一个功能强大的企业级 API 监控工具，使用 Go 语言编写。它提供接口测试、持续监控、系统资源采集、数据指标告警和定期报告等一站式能力，帮助团队实时掌握 API 服务健康状态。

---

## 核心功能矩阵

| 模块 | 功能 | 说明 |
|------|------|------|
| **PSV 测试** | 接口自动化测试 | 通过 PSV/CSV 文件定义测试用例，支持变量提取、前置/后置条件、流式断言 |
| **接口监控** | 持续在线监控 | 按配置周期自动执行测试用例，支持慢响应/失败告警 |
| **数据采集器** | JSON 指标采集 | 从任意 HTTP 接口通过 JSONPath 提取指标（CPU/内存等），支持阈值告警 |
| **系统监控** | 主机资源监控 | 采集本机 CPU、内存、磁盘、网络速率，支持 ASCII 图表和邮件告警 |
| **报告系统** | 多周期报告 | 自动生成日报/周报/月报/年报，统计成功率、平均耗时、告警汇总 |
| **告警调度** | 统一告警分发 | 三类告警源（接口/采集/系统）合并为统一邮件通知，支持冷却抑制 |
| **自动清理** | 数据生命周期 | 按保留天数自动清理日志、报告、历史数据 |

---

## 命令行使用

```bash
# 运行一次性测试（-t 或 --test 标志）
gwatch -t [paths...] [--tags tag1,tag2]

# 启动持续监控模式（默认）
gwatch [paths...] [--tags tag1,tag2]

# 运行数据采集器（scraper）
gwatch scraper

# 探测 JSON 接口结构（辅助工具）
gwatch probe <url>

# 生成系统资源报告
gwatch sys-report
```

## 技术栈

| 类别 | 技术 | 用途 |
|------|------|------|
| 语言 | Go 1.22+ | 主开发语言 |
| HTTP 客户端 | go-resty/resty | 接口请求与测试 |
| 参数校验 | cobra | 命令行框架 |
| 日志 | uber-go/zap | 结构化日志 |
| JSON 解析 | tidwall/gjson / olive/jsonpath | JSONPath 提取与 JSON 比对 |
| 系统监控 | shirou/gopsutil | CPU/内存/磁盘/网络采集 |
| 邮件 | go-mail/mail | SMTP 邮件发送 |
| 配置 | viper | YAML 配置加载 |
| 数据存储 | CSV 文件 | 历史数据持久化 |

## 运行时目录结构

```
gwatch.exe                  # 可执行文件

  └── config.yaml           # 主配置文件
cases/                      # PSV 测试用例目录（可选）
  └── *.psv                 # PSV 测试用例文件
reports/                    # 报告输出目录（自动创建）
data/                       # 数据存储目录（自动创建）
logs/                       # 日志目录（自动创建）
```
